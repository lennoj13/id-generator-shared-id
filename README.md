# NJ ID Generator

> **Live Demo:** [https://nj-id-generator.vercel.app/](https://nj-id-generator.vercel.app/)

A modern, web-based tool built with React and Vite for generating realistic simulated university schedule portals and student ID cards for creative, design, and mockup purposes.

---

## ⚠️ Disclaimer

> The creator and contributors of this project assume no responsibility or liability for any misuse of this application or the images and documents generated by it. All generated schedules, student IDs, and materials are simulated mockups and hold no official or legal validity.

---

## ✨ Features

- **University Templates:** Presets inspired by various institutions (Harvard, MIT, Minnesota State University, etc.).
- **Customizable Details:** Easily edit student name, ID number, major, term, courses, and more.
- **Realistic Schedules & ID Cards:** Instant live preview with authentic typography, styling, and layouts.
- **High-Quality Export:** Generate and download high-resolution images of your mockups directly from your browser.
- **Modern UI:** Built with sleek glassmorphism aesthetics, responsive layouts, and smooth animations.

---

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/)
- **Bundler / Build Tool:** [Vite](https://vitejs.dev/)
- **Routing:** [React Router DOM](https://reactrouter.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Styling:** Vanilla CSS (Glassmorphism & modern design system)
- **Deployment:** [Vercel](https://vercel.com/)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18+ recommended)
- `npm` or `yarn` / `pnpm`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/lennoj13/id-generator-shared-id.git
   cd id-generator-shared-id
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
