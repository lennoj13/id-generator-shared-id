## Descripción

Una aplicación web construida con React y Vite que permite generar interfaces simuladas de portales universitarios y credenciales de estudiantes para propósitos creativos y de demostración. 

## Tecnologías

- React 19
- Vite
- React Router DOM
- Lucide React (Iconos)
- Vanilla CSS (Glassmorphism & Diseño Moderno)

## Cómo ejecutar el proyecto localmente

1. Clona este repositorio.
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
